## 原始样式库存

Figma 文件未定义以下本地资产：[O]

- Variables：0
- Text Styles：0
- Paint Styles：0
- Effect Styles：0
- Grid Styles：0

因此 `tokens.dtcg.json` 和 `tokens.json` 是从重复原始属性中抽象出的 2.0 语义层，不是对既有 Figma Variables 的直接导出。后续若将令牌回写 Figma，应保留相同语义命名，不能把原始值的偶发差异继续扩散。[D]

侧栏弥散背景的原始填充来自一张包含可辨识内容的截图，但画板中只在白色 80% + 200 px 模糊下使用。本包不保存该原图，避免把设计上下文中的个人信息变成交付依赖。实现应使用隐私安全的冷色弥散背景。[R]

## 2.0 与 1.0 的关键差异

| 项目 | 1.0 | 2.0 |
| --- | --- | --- |
| 基准视口 | 1440 × 900 | 1200 × 800 |
| 常规侧栏 | 旧尺寸与结构 | 260 px 玻璃侧栏 |
| 主内容列 | 旧版布局 | 776 px，x=342 |
| 首页主工作面 | 偏灰工作区 | 白色工作区 |
| 输入 | 旧版输入结构 | 776 外包层 + 768 白色面板 |
| 完成态 | 旧三栏结构 | 390 对话 + 810 编辑器 |
| 品牌语言 | 旧身份 | Eva 人物、蓝色气泡、淡蓝点阵 |

2.0 沿用 1.0 的“规范正文 + 机器令牌 + 画板追踪 + 验收门禁”方法，但数值和组件必须以新 Figma 为准。[D]
